# Security and Content Policy

## Scope

This public repository supports the **NCSEA Big Build Hackathon — Light Frame Wood Shear Walls** project. Because multiple contributors and AI coding agents collaborate on this repository, please observe both standard credential security and engineering copyright/licensing rules.

## What Must Never Be Committed

1. **Secrets and API Keys**
   - Personal AI/LLM API keys, OAuth tokens, cloud credentials, or `.env` / `.streamlit/secrets.toml` files.
   - The application itself does not require any model API key to run.

2. **Licensed or Restricted Engineering Standards & Spreadsheets**
   - Full or excerpted PDFs of copyrighted standards (including IBC 2024, ASCE 7-22, AWC SDPWS 2021, and AWC NDS 2024) without explicit redistribution permission.
   - Private or proprietary engineering spreadsheets (`.xlsx`, `.xlsb`, `.xlsm`).
   - Only documents with confirmed redistribution permission recorded in [`references/README.md`](references/README.md) may be placed in `references/public/`.

## Reporting a Vulnerability or Restricted-Content Issue

If you discover a security vulnerability, leaked credential, or accidentally committed restricted document in this repository:

- **Do not open a public GitHub issue.**
- Use GitHub's **Report a vulnerability** button under the repository's **Security** tab (Private Vulnerability Reporting) to notify the repository owner privately, or contact the repository owner directly.
